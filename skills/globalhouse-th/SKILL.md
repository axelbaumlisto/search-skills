# Global House (globalhouse.co.th): цены по запросу и категориям

Скилл только про **Global House**. Второй сайт — отдельный скилл `homepro-th`.

```bash
S=~/.pi/agent/skills/globalhouse-th/scripts
$S/gh.sh "เหล็กเส้นกลม 6"                 # поиск: 23 позиции, Ø6 ฿46–49
$S/gh.sh "กาวยาแนวบล็อกแก้ว" 2>/dev/null   # поиск по затирке: 114 позиций, 3 страницы
$S/gh.sh "category:9236"                  # категория: стеклоблок, 44 позиции
$S/gh.sh "стеклоблок" --branch GH-150      # карта категорий + филиал
$S/gh.sh "арматура" --no-cache
```

Вывод: `URL (страниц: N) | พบ N รายการ | branch GH-150`, дальше `฿цена  название` + ссылка.

## Как устроено (не переоткрывать)

- **Поиск — параметр `keyword=`**: `https://globalhouse.co.th/search?keyword=<utf8>`.
  С `?q=` страница отдаёт только блок «похожих товаров» (трубы, тапки) — это не «нет товара».
- **Пагинация**: `&page=1..N`, по ~40 карточек, страницы не пересекаются, последняя неполная,
  дальше 0. Проверено: 40 + 40 + 34 = **114** = «พบ 114 รายการ». Скилл идёт по страницам,
  пока страница не вернёт 0 новых (`--max-pages`, по умолчанию 30).
- **Цена** лежит не в ссылке, а в карточке на 1–5 уровней выше: `55 .-` (у акции `159 .- 180.-`).
  Если искать цену только в самой ссылке — из 40 карточек распознаётся 16.
- **Филиал**: кука `gbh_branch` (по умолчанию `GH-150`); `--branch GH-xxx` подставляет её
  на время запроса и возвращает прежнюю. Цены от филиала зависят («ราคาต่างกันตามพื้นที่»).
- **Категории** (fallback): `/category/<id>`, карта `9236` стеклоблок, `90009` арматура;
  авто-подбор по названию — из `GET /api/category/menufull`. Финальные цены подставляет
  `POST /api/product/branch-saleprice`.
- Нужен браузер: удалённый Chrome по CDP на хосте `spex` (переопределяется `THAI_MAT_HOST`),
  поэтому запрос идёт через `scp`+`ssh`. Ответы кэшируются на час.

## Грабли

1. `?q=` вместо `?keyword=` — главная ловушка, выглядит как «мусор в выдаче».
2. Скролл вместо `&page=` — не поможет: лента не догружается, надо листать страницы.
3. Пересечение `page=1 ∩ page=2 = 0` — страницы не дублируются, но и не сортируются
   предсказуемо между запросами.
4. Самопроверка: `python3 ~/.pi/agent/skills/_thai_shared/selftest.py`.
